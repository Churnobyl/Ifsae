#### Redis
- Redis : Remote Dictionary Server
- "Key-Value" 구조의 비정형 데이터를 저장하고 관리하기 위한 오픈 소스 기반의 비관계형 데이터베이스 관리 시스템

#### Redis의 특징
- 메모리 기반의 데이터베이스이기 때문에 일반적으로 RDBMS보다 데이터를 빠르게 조회할 수 있다.
- List, Set 등 다양한 Data Type(Collection)을 지원한다.
- 대부분의 프로그래밍 언어에서 사용할 수 있는 클라이언트 라이브러리를 제공한다.
- 분산 시스템을 통해 고가용성 및 확장성을 보장하는데 사용할 수 있다.

#### Redis CLI 명령어
Set : 키와 값을 설정 -> 데이터 저장
```
SET key value
```

GET : 키에 대한 값 조회
```
GET key
```

DEL : 하나 이상의 키 삭제
```
DEL key
```

EXISTS : 키가 존재하는지 확인
```
EXISTS key
```

KEYS pattern : 주어진 패턴과 일치하는 모든 키 반환

KEYS * : 모든 키 조회

```
KEYS pattern

KEYS *
```

### 학습 내용
#### Spring Boot + Redis
build.gradle에 의존성 추가
```
implementation 'org.springframework.boot:spring-boot-starter-data-redis'
```

lettuce(Java Redis Client) 사용 예시

Config
```
@Configuration
public class RedisConfiguration {
    @Value("${spring.redis.host}")
    private String redisHost;
    @Value("${spring.redis.port}")
    private int redisPort;

    @Bean
    public RedisConnectionFactory redisConnectionFactory() {
        return new LettuceConnectionFactory(redisHost, redisPort);
    }
    @Bean
    public RedisTemplate<String, String> redisTemplate() {
        RedisTemplate<String, String> redisTemplate = new RedisTemplate<>();
        redisTemplate.setConnectionFactory(redisConnectionFactory());
        redisTemplate.setKeySerializer(new StringRedisSerializer());
        redisTemplate.setValueSerializer(new StringRedisSerializer());
        return redisTemplate;
    }
}
```

String-String 구조의 데이터를 다루는 RedisUtil 클래스 예시
```
@Component
public class RedisUtil {

    private final StringRedisTemplate stringRedisTemplate;

    // 데이터 조회
    public String getData(String key) {
        return stringRedisTemplate.opsForValue().get(key);
    }

    // 데이터 저장
    public void setData(String key, String value) {
        stringRedisTemplate.opsForValue().set(key, value);
    }

    // 만료시간 설정
    public void setDataExpire(String key, String value, long duration) {
        Duration expireDuration = Duration.ofSeconds(duration);
        stringRedisTemplate.opsForValue().set(key, value, expireDuration);
    }

    // 데이터 삭제
    public void deleteData(String key) {
        stringRedisTemplate.delete(key);
    }

    // 키 존재 여부 확인
    public boolean exists(String key) {
        return stringRedisTemplate.hasKey(key);
    }
}
```
