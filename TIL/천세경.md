# ELasticSearch 분석기 (analyzer)
> ElasticSearch 문서의 내용은 분석기에 의해 인덱싱 처리 되고 생산된 토큰으로 검색된다. 따라서 목적에 따라 어떤 분석기를 사용할 지, 언제 분석기를 사용할지 길행 순서가 중요하다. 너무 많은 분석기를 거치면 인덱싱 성능이 저하될 수 있다. 색인과 검색의 분석기는 가급적 같은 tokenizer를 사용하는게 바람직하지만 경우에 따라 색인과 검색에 다른 분석기를 사용할 수도 있다.

## 1. 분석기 구성 요소
> **Analyzer** : Full text 검색을 위해 문장을 토큰화 하여 검색 시 매칭 될 수 있도록 분석하는 과정을 담당.
>  - 분석기는 **character filter + tokenizer + token filters** 로 구성할 수 있다.

- **"character filter"**
    - 원본 텍스트를 전처리 하는 것
    - 기본적으로 html_strip, mapping, pattern_replace를 제공
        - **"html_strip"** : html형식의 full text 입력 시 html태그들을 전부 삭제하고 text형태의 글로 만들어줌.
        - **"mapping"**
        - **"pattern_replace"**
- **"tokenizer"**
    - Character filter에서 변형된 텍스트를 특정 규칙에 맞게 토큰으로 분할
    - 분석기 구성 시 한 개만 사용 가능
- **"token filters"**
    - tokenizer에서 분할된 토큰들을 개별적으로 문자를 추가, 수정, 삭제하는 필터
    - 배열의 형태로 여러개의 필터를 사용할 수 있음

- **예시**
```
PUT /my_index
{   
    "settings": {
        "analysis": {
            "analyzer": {
                "custom_analyzer": {
                "type": "custom",
                "char_filter": ["html_strip"],
                "tokenizer": "whitespace",
                "filter": ["lowercase", "stop"]
                }
            }
        }
    }
}
```

## 2. 한글 분석기 nori
> nori 분석기는 ELasticSearch에서 한국어 텍스트 처리를 위해 공식적으로 제공하는 분석기이다. 한국어는 어절이 띄어쓰기에 민감하고, 조사와 어미 변화가 많아 영어와응 다은 방식으로 처리해야 하기때문에 nori분석기를 사용해야한다. nori는 기본 패키지가 아니므로 사용하기 전 설치해서 사용한다.
> - 명령어
    <pre>
    <code>bin/elasticsearch-plugin install analysis-nori
    </code>
    </pre>
<br>

### 구성 요소

1. **Tokenizer** : nori_tokenizer
    > nori_tokenizer는 user_dictionary, user_dictionary_rules, decompound_mode 등으로 구성되어 있다. 예를 들어, **"안녕하세요"** 라는 문장을 **"안녕", "하", "세요"**의 형태의 형태소로 분리할 수 있다.

    - **user_dictionary** : 사용자 사전 파일을 설정. 단일 명사, 복합 명사 등을 등록한다. 기본 폴더 위치는 $ES_NOME/config/파일명.txt로 만들어 사전을 한줄에 하나씩 처리한다.
    - **user_dictionary_rules** : 인덱스 세팅에서 단일명사, 복합명사를 등록하고 관리한다.
    - **decompound_mode** : default는 discard로 복합 명사를 처리 할 때 어떻게 나누어 색인할지 결정한다. **"국회의원"**을 예로 들면,
        - **none** : 복합 명사를 분해하지 않음. **->**"국회의원"
        - **discard** : 복합 명사를 분해하고 원 단어 삭제. **->** "국회", "의원"        
        - **mixed** : 복합 명사로 분해한 단어와 원본 단어를 모두 유지 **->** "국회의원", "국회", "의원"
    - **discard_punctuation** : default는 true. 구두점(쉽표, 마침표)을 삭제할 지에 대한 여부를 설정한다.
    
2. **Token filter** : nori_part_of_speech, nori_readingform, nori_number
    - **"nori_part_of_speech"** : 품사에 따라 필터링을 수행한다. 불필요한 조사를 제거하거나 명사만 남기고 싶을 때 사용한다.
        - 예시 : <pre>
    <code>{
  "type": "nori_part_of_speech",
  "stoptags": ["E", "J", "IC"]
}
    </code>
    </pre>
        - stoptags에 들어가는 정보는 [한글 품사 약어 정보](https://hacktam.kr/etclec/72)
    - **"nori_readingform"** : 한자로 입력된 텍스트를 한글 발음으로 변환해준다. 한자가 포함된 텍스트를 검색할 때 한글 발음으로 검색이 가능하다.
    - **"nori_number"** : 숫자 필터. 한국어 숫자를 아라비아 숫자로 변환하거나, 그 반대로 변환하는 기능을 제공한다.
3. 예시
```
PUT /korean_index
{
  "settings": {
    "analysis": {
      "analyzer": {
        "nori_analyzer": {
          "type": "custom",
          "tokenizer": "nori_tokenizer",
          "filter": ["nori_part_of_speech", "nori_readingform", "nori_stop"]
        }
      },
      "tokenizer": {
        "nori_tokenizer": {
          "type": "nori_tokenizer",
          "decompound_mode": "mixed",
          "user_dictionary": "userdict_ko.txt"
        }
      }
    }
  }
}
```
