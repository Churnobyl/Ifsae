# 잎새 프로젝트

## Install

### 1. Install Node.js
Install Node.js v20.17.0

https://nodejs.org/en

### 2. Install yarn
#### 2-1. Enable corepack
Because a corepack was installed with nodejs, just enable the corepack.
~~~bash
corepack enable
~~~

### 3. git clone project
~~~bash
git clone https://github.com/EasterEggA508/ifsavedog-FE.git
~~~

### 4. yarn install
~~~bash
yarn install
~~~

### 5. yarn run dev
~~~bash
yarn run dev
~~~
